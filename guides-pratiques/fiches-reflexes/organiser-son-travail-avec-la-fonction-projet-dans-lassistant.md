# Organiser son travail avec la fonction Projet dans l’Assistant

{% columns %}
{% column %}
Utilisez un projet si vous réutilisez les **mêmes documents** ou **consignes** dans plusieurs conversations.

1. **Créez un projet** depuis la barre latérale : donnez-lui un nom, un logo et une couleur pour le repérer facilement.
2. **Ajoutez-y** les documents et les instructions permanentes utiles.
3. **Démarrez une conversation** dans le projet : chaque réponse s'appuie automatiquement sur ces documents et instructions.

> **Exemple :**
>
> « Créer un projet « Rapport d’activité 2026 », ajouter les fiches de suivi, puis demander une synthèse consolidée. »
{% endcolumn %}
