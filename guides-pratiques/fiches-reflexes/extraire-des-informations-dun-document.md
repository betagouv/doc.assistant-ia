# Extraire des informations d'un document

{% columns %}
{% column %}
1. **Cliquer sur « + »** (glisser-déposer ou bouton dédié) : puis séléctionner "_joindre un ficher"._
2. **Joignez le document** (glisser-déposer ou bouton dédié) : <mark style="color:red;background-color:red;">**10 Mo maximum**</mark> par message.
3. **Formulez votre demande** avec des mots-clés de contenu plutôt que des repères visuels comme « page 12 » ou « la sous section sur les normes environnementales ».
4. **Vérifiez les informations** délivrées avant de les réutiliser.

{% prompt description="Exemple de prompt" icon="lightbulb" defaultExpanded="full" %}
```markdown
« Dans ce rapport, liste les recommandations sous forme de tableau avec pour chacune : titre, priorité, échéance. »
```
{% endprompt %}
{% endcolumn %}
