# Rédiger son premier prompt



{% columns %}
{% column width="50%" %}
Connectez-vous via **ProConnect** sur [assistant.numerique.gouv.fr](https://assistant.numerique.gouv.fr/home/), puis démarrez une conversation depuis la barre de saisie centrale.

1. **Donnez le contexte** : qui vous êtes, dans quel cadre vous écrivez.
2. **Précisez la tâche demandée**, de façon claire et concrète.
3. **Indiquez le format** de réponse attendu (longueur, ton, structure).

{% prompt description="Exemple de prompt" icon="lightbulb" defaultExpanded="full" %}
```markdown
« Tu es un agent RH. Rédige un mail de convocation à un entretien annuel, ton formel, 150 mots maximum. »
```
{% endprompt %}
{% endcolumn %}
